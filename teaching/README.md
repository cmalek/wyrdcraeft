# Teaching Workspaces

This repo now keeps teaching materials in two separate workspaces:

- `oe-grammar/`: Old English grammar, reading, pronunciation, and translation.
- `machine-assistance/`: technical work for OCR, structured data, retrieval, evaluation, and agent support around Old English.

Each subdirectory is its own teaching workspace with its own:

- `MISSION.md`
- `RESOURCES.md`
- `NOTES.md`
- `lessons/`
- `reference/`
- `learning-records/`

Shared front-end assets live in `shared/assets/`.

When adding a new lesson, choose the workspace by the outcome:

- If the result is "I can read or translate Old English better," put it in `oe-grammar/`.
- If the result is "I can build or improve tooling that helps with Old English," put it in `machine-assistance/`.
