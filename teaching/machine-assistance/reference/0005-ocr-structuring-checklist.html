OCR Structuring Checklist

Use this when you are turning a hard, image-only Old English PDF into machine-usable data without losing the original evidence.

One-line rule: treat OCR output as a witness, not as final truth. Corrections belong in overlays or derived structure, not by erasing the raw evidence.

Pipeline

StageGoalMain artifactStop if...
1. AcquireGet stable page images or PDF pagessource PDF / page imagesthe source is incomplete or mixed with unrelated pages
2. PrepareNormalize page inputs for OCRpage images / tiles / page PDFslayout damage is introduced by preprocessing
3. OCRGenerate readable witness textmarkdown or raw text witnessyou cannot recover page provenance
4. ValidateMeasure quality, not vibesCER / WER / character-preservation metricsthorn, macrons, or table structure collapse badly
5. AnchorTie text back to page/region/lineanchors / spans / bbox linkstext cannot be traced back to image evidence
6. AdjudicateRecord only the exceptions humans must fixoverlay or review notesyou are silently rewriting raw OCR in place
7. ExportProduce derived, structured dataJSON / YAML / JSONL bundlethe structure cannot point back to witnesses

Hard-PDF Failure Modes

If you see...Likely problemFirst response
p for þ or ðglyph confusion in noisy scanstrack character-preservation metrics before broad correction
macrons dropped or flattenedimage quality or model weakness on diacriticstreat diacritic recall as a separate gate
Greek or linguistic symbols normalized awaymodel over-regularizationkeep a diplomatic witness and compare against image snippets
tables linearized into nonsensereading-order collapsepreserve table witness separately from prose witness
good prose but wrong structurelayout anchoring lostrecover page/region/line evidence before parsing harder
cleaned text with no traceabilityover-eager post-correctionreintroduce raw witness and overlay layers

Minimal-Human-Involvement Rules

Automate generation: source prep, OCR, normalization, scoring, bundle assembly.
Gate automatically: fail runs that lose thorns, macrons, or layout integrity.
Review by exception: humans should touch only uncertain spans, not retype whole pages.
Never destroy evidence: corrections add layers; they do not replace witnesses.
