# Issue tracker: Trello

Issues, feature ideas, and larger project ideas for this repo live in Trello on
the `wyrdcraft` board:

- Board URL: https://trello.com/b/dSDeIOIY/wyrdcraft

## Conventions

The board lists are the source of truth for work state:

- **Reference** - reference material and package lists; informational only, not
  part of the active delivery flow
- **Phase infinity** - ideas or tasks we may do someday, but do not want to
  work on now
- **Backlog** - tasks we do want to work on, but have not scheduled yet
- **On Deck** - tasks we intend to work on and have scheduled
- **Doing** - tasks currently in progress
- **For release** - tasks implemented in the codebase and committed to git, but
  not yet included in a semver release
- **Release** - tasks completed and included in a semver release

Treat cards on this board as the repo's issue tracker surface unless the user
explicitly says otherwise.

## When a skill says "publish to the issue tracker"

Create or update a Trello card on the `wyrdcraft` board in the list that best
matches the intended state.

## When a skill says "fetch the relevant ticket"

Open the matching Trello card on the `wyrdcraft` board and use its title,
description, comments, labels, and list placement as the current source of
truth.
